# Employee Management System

Full-stack project using:
- React + Vite + Tailwind CSS
- Axios + React Router
- Context API
- Node.js + Express.js
- JWT + bcrypt + Multer
- MySQL + Sequelize
- Pagination, Authorization, Error Handling

## Run
1. Create MySQL database: `employee_management`
2. Configure `backend/.env`
3. Backend:
   ```bash
   cd backend
   npm install
   npm run dev
   ```
4. Frontend:
   ```bash
   cd frontend
   npm install
   npm run dev
   ```

Default admin is created automatically from `.env`.
